# Bài 13 — Muốn có · muốn làm · đi để… · ほしいです／〜たいです／N に行（い）きます

> Nguồn: [Học tiếng Nhật N5 cùng Minato — Bài 13](https://www.youtube.com/watch?v=9No9ipFAe7A&list=PLbBhikLbVlB0GaIO_rfgGtkTqSS70lS_k)

---

## 0. Lời khuyên trước khi học

Bài này nói về **mong muốn của người nói** (và hỏi người nghe).  
**Không dùng** ほしい／たい để khẳng định ý muốn của **người thứ ba** (Lan muốn…, anh ấy muốn…) — cách nói đó học sau (N3).

> Phân biệt: muốn **có** vật/người → **ほしい** · muốn **làm** hành động → **たい**.

---

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

- Nói **muốn có** gì: N が ほしいです
- Nói **muốn làm** gì: V-ます bỏ ます + たいです
- Hỏi người đối diện muốn gì / muốn làm gì
- Nói **đi / đến / về để làm gì**: N に 行（い）きます／来（き）ます／帰（かえ）ります

| # | Nội dung | Ví dụ tiếng Việt |
|---|----------|------------------|
| 1 | Muốn có | Tôi muốn có điện thoại mới. |
| 2 | Muốn làm | Tôi muốn ăn sushi. |
| 3 | Đi để… | Đi bơi / đi chơi. |

---

## 2. Muốn có — 「N が ほしいです」

### Cấu trúc

```
（わたしは） N  が  ほしいです。
```

**Nghĩa:** Tôi muốn có N.

- **ほしい** chia như **tính từ い**
- Tân ngữ mong muốn thường kèm **が** (không dùng を)

### Chia ほしい như い-adj

| Thể | Dạng |
|-----|------|
| Khẳng định | ほしいです |
| Phủ định | ほしくないです |
| Nghi vấn | ほしいですか |
| Quá khứ | ほしかったです |

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi muốn có điện thoại di động. | 携帯電話（けいたいでんわ）がほしいです。 |
| Tôi muốn có người yêu đẹp trai. | ハンサムな恋人（こいびと）がほしいです。 |
| Tôi muốn có nhiều tiền. | お金（おかね）がたくさんほしいです。 |
| Tôi muốn có sức khỏe. | 健康（けんこう）がほしいです。 |
| Tôi muốn có bạn bè. | 友（とも）だちがほしいです。 |
| Tôi muốn có con. | 子（こ）どもがほしいです。 |
| Tôi muốn có giày Adidas. | アディダスの靴（くつ）がほしいです。 |

### Hỏi người nghe

Bỏ chủ ngữ khi hỏi trực tiếp:

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Bạn muốn cái mũ này không? | この帽子（ぼうし）がほしいですか。 |
| → Có, tôi muốn. | はい、ほしいです。 |
| Bạn muốn xe máy không? | バイクがほしいですか。 |
| → Không, tôi muốn ô tô. | いいえ、ほしくないです。車（くるま）がほしいです。 |
| Bạn muốn có người yêu không? | 恋人（こいびと）がほしいですか。 |
| Bạn muốn quà sinh nhật gì? | 誕生日（たんじょうび）のプレゼントは何（なに）がほしいですか。 |
| Bạn muốn người yêu như thế nào? | どんな恋人（こいびと）がほしいですか。 |
| Bây giờ bạn muốn gì nhất? | 今（いま）いちばん何（なに）がほしいですか。 |

### Lưu ý quan trọng

1. Chỉ nói **ý muốn của mình** / hỏi **người nghe**  
2. Không nói: ✕ ナムさんは車（くるま）がほしいです。 (ý muốn người thứ ba — tránh ở N5)

---

## 3. Muốn làm — 「V-ますぼ ます + たいです」

### Cấu trúc

```
Vます  →  bỏ ます  →  〜たいです
```

**Nghĩa:** Tôi muốn làm V.

| Động từ ます | → muốn |
|--------------|--------|
| 書（か）きます | 書（か）きたいです |
| 食（た）べます | 食（た）べたいです |
| 飲（の）みます | 飲（の）みたいです |
| 見（み）ます | 見（み）たいです |
| 買（か）います | 買（か）いたいです |
| 行（い）きます | 行（い）きたいです |
| 休（やす）みます | 休（やす）みたいです |

### たい chia như tính từ い

| Thể | Dạng |
|-----|------|
| Khẳng định | 〜たいです |
| Phủ định | 〜たくないです |
| Nghi vấn | 〜たいですか |
| Quá khứ | 〜たかったです |

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi muốn mua TV. | テレビが／を買（か）いたいです。 |
| Tôi muốn ăn sushi. | 寿司（すし）が／を食（た）べたいです。 |
| Tôi muốn viết thư cho người yêu. | 恋人（こいびと）に手紙（てがみ）を書（か）きたいです。 |
| Tôi không muốn đi học. | 学校（がっこう）へ行（い）きたくないです。 |
| Tôi không muốn uống thuốc. | 薬（くすり）を飲（の）みたくないです。 |
| Tôi muốn tặng hoa cho mẹ. | 母（はは）に花（はな）をあげたいです。 |
| Tôi muốn nói chuyện bằng tiếng Nhật. | 日本語（にほんご）で話（はな）したいです。 |
| Ngày mai tôi muốn gửi thư cho bố. | あした父（ちち）に手紙（てがみ）を送（おく）りたいです。 |
| Tôi muốn gọi điện cho gia đình. | 家族（かぞく）に電話（でんわ）をかけたいです。 |
| Tôi muốn chụp ảnh với Minh. | ミンさんと写真（しゃしん）を撮（と）りたいです。 |

### を ↔ が với たい

Có thể đổi **を → が** để **nhấn mạnh** đối tượng muốn làm:

| Bình thường | Nhấn mạnh |
|-------------|-----------|
| 本（ほん）を読（よ）みたいです。 | 本（ほん）**が**読（よ）みたいです。 |
| テンプラを食（た）べたいです。 | テンプラ**が**食（た）べたいです。 |
| 音楽（おんがく）を聞（き）きたいです。 | 音楽（おんがく）**が**聞（き）きたいです。 |

### Hỏi với từ để hỏi

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Ở Nhật bạn muốn mua gì? | 日本（にほん）で何（なに）が／を買（か）いたいですか。 |
| Bạn muốn đi đâu? | どこへ行（い）きたいですか。 |
| Bạn muốn làm gì? | 何（なに）をしたいですか。 |
| Bạn muốn ăn gì? | 何（なに）が／を食（た）べたいですか。 |
| Taro muốn về quê không? | （太郎（たろう）さんは）田舎（いなか）へ帰（かえ）りたいですか。 |
| Bạn muốn đọc cuốn sách này không? | この本（ほん）を読（よ）みたいですか。 |

## 4. Đi / đến / về để làm gì — 「N／Vますぼます に 行（い）きます」

### Cấu trúc

```
場所（ばしょ） へ  目的（もくてき） に  行（い）きます／来（き）ます／帰（かえ）ります。
目的（もくてき） に  行（い）きます。
```

**Nghĩa:** Đi (đến / về) **để** làm mục đích đó.

Mục đích = **danh từ hành động** hoặc **thân ます** (bỏ ます):

| Mục đích | Cách nói |
|----------|----------|
| bơi | 泳（およ）ぎに行（い）きます |
| chơi | 遊（あそ）びに行（い）きます |
| mua sắm | 買（か）い物（もの）に行（い）きます |
| ăn | 食（た）べに行（い）きます |
| gặp | 会（あ）いに行（い）きます |

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi đi bơi. | 泳（およ）ぎに行（い）きます。 |
| Cuối tuần đi chơi. | 週末（しゅうまつ）遊（あそ）びに行（い）きます。 |
| Đi ăn sushi. | 寿司（すし）を食（た）べに行（い）きます。 |
| Đến Nhật để học tiếng Nhật. | 日本語（にほんご）を勉強（べんきょう）しに日本（にほん）へ来（き）ます。 |
| Về quê để gặp bố mẹ. | 両親（りょうしん）に会（あ）いに田舎（いなか）へ帰（かえ）ります。 |
| Đi siêu thị mua đồ. | 買（か）い物（もの）にスーパーへ行（い）きます。 |

> Động từ hướng (**行（い）きます・来（き）ます・帰（かえ）ります**) giữ ở cuối; mục đích + **に** đứng trước.

---

## 5. Tổng kết nhanh

| Mong muốn | Công thức |
|-----------|------------|
| Muốn có N | N **が ほしいです** |
| Không muốn có | N が **ほしくないです** |
| Muốn làm V | Vます bỏ ます + **たいです** |
| Không muốn làm | 〜**たくないです** |
| Đi để làm | （場所（ばしょ）へ）目的（もくてき）**に行（い）きます** |

**Luôn nhớ**

1. ほしい／たい ≈ tính từ **い** khi chia
2. Chỉ nói ý muốn **của mình** (hoặc hỏi người nghe)
3. Muốn **có** ≠ muốn **làm**
4. Đi để… → mục đích + **に** + 行（い）く／来（く）る／帰（かえ）る

---

## 6. Hội thoại mẫu (tổng hợp)

A: 誕生日（たんじょうび）に何（なに）がほしいですか。  
B: 新（あたら）しいかばんがほしいです。赤（あか）いのがほしいです。  
A: 週末（しゅうまつ）何（なに）をしたいですか。  
B: 海（うみ）で泳（およ）ぎに行（い）きたいです。それから、寿司（すし）も食（た）べたいです。  
A: いいですね。わたしも行（い）きたいです。

---

## 7. Bài tập tự kiểm tra

Dịch sang tiếng Nhật:

1. Tôi muốn có ô tô màu hồng.  
2. Bạn muốn cặp màu xanh không? → Không, tôi muốn cái màu đỏ.  
3. Tôi muốn nghỉ một chút.  
4. Tôi không muốn uống rượu.  
5. Bạn muốn mua gì ở Nhật?  
6. Mai tôi đi thư viện để học.

### Gợi ý đáp án

1. ピンクの車（くるま）がほしいです。  
2. 青（あお）いカバンがほしいですか。→ いいえ、赤（あか）いのがほしいです。  
3. ちょっと休（やす）みたいです。  
4. お酒（さけ）を飲（の）みたくないです。  
5. 日本（にほん）で何（なに）が／を買（か）いたいですか。  
6. あした勉強（べんきょう）しに図書館（としょかん）へ行（い）きます。
