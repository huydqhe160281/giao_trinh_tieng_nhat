# Bài 3 — Địa điểm · ここ・そこ・あそこ・どこ

> Nguồn: [Học tiếng Nhật N5 cùng Minato — Bài 3](https://www.youtube.com/watch?v=6tn9uUphZx4&list=PLbBhikLbVlB0GaIO_rfgGtkTqSS70lS_k)

---

## 0. Lời khuyên trước khi học

Ôn lại **これ・それ・あれ** (bài 2). Bài 3 cùng hệ chỉ khoảng cách, nhưng chỉ **nơi chốn**, không chỉ vật.

---

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

- Chỉ chỗ: **đây / đó / kia / đâu**
- Nói **N ở đâu** và **đây là N**
- Dùng dạng lịch sự hơn: **こちら・そちら・あちら・どちら**
- Nói xuất xứ / thuộc địa điểm: **N1 の N2** (của Mỹ, của công ty…)

| # | Nội dung | Ví dụ |
|---|----------|-------|
| 1 | ここ・そこ・あそこ・どこ | Nhà vệ sinh ở đây. |
| 2 | N は 場所（ばしょ） です | Đây là nhà ăn. |
| 3 | どこですか | Nhà bếp ở đâu? |
| 4 | こちら／そちら／あちら／どちら | Lịch sự hơn |
| 5 | Xuất xứ · tên nơi | Cái bút này của Mỹ. |

---

## 2. ここ・そこ・あそこ・どこ

### Cấu trúc

```
ここ／そこ／あそこ／どこ
```

### Phân tích khoảng cách (song song bài 2)

| Chỉ vật (bài 2) | Chỉ chỗ (bài 3) | Nghĩa |
|-----------------|-----------------|-------|
| これ | **ここ** | chỗ này (gần người nói) |
| それ | **そこ** | chỗ đó (gần người nghe) |
| あれ | **あそこ** | chỗ kia (xa cả hai) |
| 何（なん） | **どこ** | đâu / chỗ nào |

:::info Đại từ chỉ vị trí
**ここ・そこ・あそこ・どこ** thay cho tên địa điểm khi đã rõ hoặc đang chỉ tay / chỉ hướng.
:::

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Đây là nhà vệ sinh. | ここはトイレです。／ここはお手洗い（おてあらい）です。 |
| Đó là nhà ăn. | そこは食堂（しょくどう）です。 |
| Kia là nhà ga. | あそこは駅（えき）です。 |
| Chỗ kia là công ty. | あそこは会社（かいしゃ）です。 |

---

## 3. N は 場所（ばしょ） です — N ở (chỗ) …

### Cấu trúc

```
N  は  ここ／そこ／あそこ  です。
N  は  場所（ばしょ）  です。
```

**Nghĩa:** N ở đây / ở đó / là địa điểm X.

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Nhà vệ sinh ở đây. | トイレはここです。 |
| Nhà ăn ở đó. | 食堂（しょくどう）はそこです。 |
| Trường học ở chỗ kia. | 学校（がっこう）はあそこです。 |
| Đây là nhà bếp. | ここは台所（だいどころ）です。 |

> **N は 場所（ばしょ） です** = “N là / nằm ở địa điểm đó”.  
> Nói người/động vật “đang ở đâu” đầy đủ hơn → **います** (bài 9).

---

## 4. どこですか — ở đâu?

### Cấu trúc

```
N  は  どこですか。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Nhà vệ sinh ở đâu? | トイレはどこですか。 |
| → Ở đây ạ. | ここです。 |
| Văn phòng ở đâu? | 事務所（じむしょ）はどこですか。 |
| → Ở chỗ kia. | あそこです。 |
| Bạn ở đâu? | あなたはどこですか。／どこですか。 |

### Hội thoại ngắn

A: すみません。食堂（しょくどう）はどこですか。  
B: あそこです。  
A: ありがとうございます。

---

## 5. こちら・そちら・あちら・どちら — lịch sự hơn

Dùng trong giao tiếp lịch sự / chỉ đường lịch sự.

| Thường | Lịch sự hơn | Nghĩa |
|--------|-------------|-------|
| ここ | **こちら** | phía này / chỗ này |
| そこ | **そちら** | phía đó / chỗ đó |
| あそこ | **あちら** | phía kia / chỗ kia |
| どこ | **どちら** | phía nào / đâu |

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Nhà vệ sinh ở phía nào ạ? | お手洗い（おてあらい）はどちらですか。 |
| → Phía này ạ. | こちらです。 |
| Phòng họp ở phía kia. | 会議室（かいぎしつ）はあちらです。 |

:::tip
Hỏi đường / tiếp khách: ưu tiên **こちら・どちら**.
:::

---

## 6. Xuất xứ & thuộc nơi — N1 の N2

Mở rộng の (bài 1–2): nói **xuất xứ sản phẩm**, **tên nước / công ty**.

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Cái bút này là của Mỹ. | このペンはアメリカのです。／アメリカのペンです。 |
| Cái cặp này của Ý. | このかばんはイタリアのです。 |
| Tôi là nhân viên của công ty IMC. | わたしはIMCの社員（しゃいん）です。 |
| Đây là rượu của Nhật. | これは日本（にほん）のお酒（おさけ）です。 |

### Hỏi xuất xứ

```
これは  どこの  N  ですか。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Cái này của nước nào? | これはどこのですか。／どこの車（くるま）ですか。 |
| → Của Nhật. | 日本（にほん）のです。 |

## 7. Tổng kết nhanh

| Mục | Công thức |
|-----|-----------|
| Chỉ chỗ | ここ／そこ／あそこ |
| Hỏi chỗ | N は どこですか |
| Lịch sự | こちら／そちら／あちら／どちら |
| Xuất xứ | どこの N／N1 の N2 |

**Song song với bài 2**

```
これ → ここ → こちら
それ → そこ → そちら
あれ → あそこ → あちら
何（なん）   → どこ → どちら
```

## 8. Hội thoại mẫu

A: すみません。トイレはどこですか。  
B: あちらです。  
A: 食堂（しょくどう）もあそこですか。  
B: いいえ、食堂（しょくどう）はこちらです。  
A: このパンはどこのですか。  
B: フランスのです。
