# Âm ghép · っ nhỏ · Âm dài

Sau khi thuộc gojūon + tenten/maru, học thêm 3 “luật viết” này là đọc được hầu hết từ N5.

## 1. Âm ghép（拗音・ようおん）

Chữ **い段** (き・し・ち・に·…) + **ゃ / ゅ / ょ** nhỏ (không phải やゆよ to).

| | ya | yu | yo |
|--|----|----|----|
| **き** | きゃ kya | きゅ kyu | きょ kyo |
| **し** | しゃ sha | しゅ shu | しょ sho |
| **ち** | ちゃ cha | ちゅ chu | ちょ cho |
| **に** | にゃ nya | にゅ nyu | にょ nyo |
| **ひ** | ひゃ hya | ひゅ hyu | ひょ hyo |
| **み** | みゃ mya | みゅ myu | みょ myo |
| **り** | りゃ rya | りゅ ryu | りょ ryo |

Có tenten:

| | ya | yu | yo |
|--|----|----|----|
| **ぎ** | ぎゃ gya | ぎゅ gyu | ぎょ gyo |
| **じ** | じゃ ja | じゅ ju | じょ jo |
| **び** | びゃ bya | びゅ byu | びょ byo |
| **ぴ** | ぴゃ pya | ぴゅ pyu | ぴょ pyo |

Katakana: キャ · シャ · ジャ · ピョ… (ゃゅょ nhỏ tương ứng ャュョ)

:::warning Sai thường gặp
`きや` (き + や **to**) ≠ `きゃ` (ghép).  
Viết **nhỏ** thì mới là một âm tiết.
:::

### Ví dụ

| Từ | Đọc |
|----|-----|
| きゃく | kyaku — khách |
| しゃしん | shashin — ảnh |
| いっしょ | issho — cùng nhau |
| びょういん | byōin — bệnh viện |
| りょうり | ryōri — món ăn / nấu ăn |

## 2. っ nhỏ（促音・そくおん）— ngắt âm

Hiragana: **っ** · Katakana: **ッ**

Làm **đôi phụ âm** sau đó / dừng hơi một nhịp:

| Viết | Đọc | Nghĩa |
|------|-----|--------|
| がっこう | gak**k**ō | trường |
| きっぷ | kip**p**u | vé |
| みっつ | mit**t**su | 3 cái |
| ベッド | bed**d**o | giường |

Không có っ đứng cuối từ (trừ hiệu ứng âm thanh).

## 3. Âm dài（長音・ちょうおん）

Giữ nguyên âm **gấp đôi thời gian**.

### Trong hiragana

| Cách | Ví dụ |
|------|--------|
| Thêm nguyên âm cùng hàng | おかあさん (kā) · おにいさん (nī) |
| え行 + い | えいが (ē / ei) · せんせい |
| お行 + う | ありがとう (tō) · ほうりつ |

### Trong katakana

Thường dùng dấu **ー**:

| Viết | Đọc |
|------|-----|
| コーヒー | kōhī |
| スーパー | sūpā |
| タクシー | takushī |

## Checklist đọc một từ lạ

1. Tách gojūon / tenten / maru  
2. Có **ゃゅょ** nhỏ không?  
3. Có **っ** không?  
4. Có âm dài (ー hoặc nguyên âm đôi) không?  
5. Đọc chậm từng mora → nối lại
