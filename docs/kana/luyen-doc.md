# Luyện đọc kana

Dùng trang này như checklist hàng ngày — 10–15 phút là đủ.

## Checklist tiến độ

- [ ] Thuộc あ→ん (hiragana) — đọc xuôi bảng  
- [ ] Viết lại từ trí nhớ ≥ 1 lần / hàng  
- [ ] Thuộc tenten hàng g/z/d/b  
- [ ] Thuộc maru hàng p  
- [ ] Đọc được âm ghép きゃ・しゃ・ちゃ…  
- [ ] Nghe / đọc đúng từ có っ  
- [ ] Katakana: đọc được tên nước + đồ vật N5  
- [ ] Đọc lướt được ví dụ trong [Bài 1](/docs/bai-01-cau-danh-tu) không phụ thuộc romaji

## Đọc theo hàng (hiragana)

```
あいうえお
かきくけこ　がぎぐげご
さしすせそ　ざじずぜぞ
たちつてと　だぢづでど
なにぬねの
はひふへほ　ばびぶべぼ　ぱぴぷぺぽ
まみむめも
や　ゆ　よ
らりるれろ
わをん
```

## Đọc từ hỗn hợp

| Từ | Ghi chú |
|----|---------|
| わたし | hiragana thuần |
| です | |
| がくせい | có が |
| せんせい | âm dài せい |
| ベトナム | katakana |
| コーヒー | ー dài |
| きっぷ | っ |
| しゃしん | âm ghép |
| びょういん | ghép + dài |
| ありがとう | とう dài |

## Kết nối sang Minna

Khi đọc được ~80% bảng, vào ngữ pháp ngay — đừng chờ “thuộc 100% mới học Bài 1”. Vừa học Minna vừa gặp lại kana sẽ nhớ lâu hơn.
