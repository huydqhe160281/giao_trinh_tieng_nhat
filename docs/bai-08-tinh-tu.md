# Bài 8 — Tính từ · い形容詞（けいようし）・な形容詞（けいようし）

> Nguồn: [Học tiếng Nhật N5 cùng Minato — Bài 8](https://www.youtube.com/watch?v=Vue8Wms6lzM&list=PLbBhikLbVlB0GaIO_rfgGtkTqSS70lS_k)

---

## 0. Lời khuyên trước khi học

Thuộc danh sách tính từ đuôi **い** và **な** trong từ vựng bài. Nhận đúng loại tính từ thì chia khẳng định / phủ định không bị sai.

---

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

- Phân biệt **tính từ đuôi い** và **đuôi な**
- Nói câu vị ngữ: **N は Adj です**
- Bổ nghĩa danh từ: **Adj + N**
- Hỏi cảm nhận: **どうですか**
- Dùng mức độ **とても／あまり**
- Nối câu bằng **そして** và đối lập **が**

| # | Nội dung | Ví dụ |
|---|----------|-------|
| 1 | い／な 形容詞（けいようし） | ngon / tiện lợi |
| 2 | N は Adj です | Phở ngon. |
| 3 | Adj + N | bát phở ngon |
| 4 | どうですか | Thế nào? |
| 5 | とても／あまり | rất / không … lắm |
| 6 | そして／が | và / nhưng |

---

## 2. Hai loại tính từ

### い形容詞（けいようし） — kết thúc bằng い

| Tính từ | Nghĩa |
|---------|-------|
| おいしい | ngon |
| たかい | cao / đắt |
| やすい | rẻ |
| おおきい | to |
| ちいさい | nhỏ |
| あたらしい | mới |
| ふるい | cũ |
| いい／よい | tốt |
| わるい | xấu / tệ |
| あつい | nóng (trời) / nóng (đồ) |
| さむい | lạnh (trời) |
| おもしろい | thú vị / hay |

:::warning
**きれい** kết thúc bằng い nhưng là **な形容詞（けいようし）** (không chia như い).
:::

### な形容詞（けいようし） — gốc + な khi bổ nghĩa danh từ

| Tính từ | Nghĩa |
|---------|-------|
| しずか（な） | yên tĩnh |
| にぎやか（な） | nhộn nhịp |
| しんせつ（な） | tốt bụng |
| ゆうめい（な） | nổi tiếng |
| べんり（な） | tiện lợi |
| きれい（な） | đẹp / sạch |
| すき（な） | thích *(hay gặp; chi tiết bài sau)* |
| きらい（な） | ghét |

---

## 3. Câu vị ngữ — N は Adj です

### Khẳng định

```
N  は  いAdj  です。
N  は  なAdj  です。     ← không thêm な trước です
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Phở ngon. | フォーはおいしいです。 |
| Thầy giáo đẹp trai. | 先生（せんせい）はハンサムです。 |
| Tokyo nhộn nhịp. | 東京（とうきょう）はにぎやかです。 |
| Căn hộ này tiện lợi. | このアパートは便利（べんり）です。 |

### Phủ định

| Loại | Công thức |
|------|-----------|
| いAdj | bỏ **い** → **くありません**／**くないです** |
| なAdj | **じゃありません**／**ではありません** |

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Không ngon. | おいしくありません。／おいしくないです。 |
| Không đắt. | 高（たか）くありません。 |
| Không yên tĩnh. | 静か（しずか）じゃありません。 |
| Không đẹp. | きれいじゃありません。 |

---

## 4. Bổ nghĩa danh từ — Adj + N

```
いAdj + N
なAdj + な + N
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Bát phở ngon | おいしいフォー |
| Người tốt bụng | 親切（しんせつ）な人（ひと） |
| Thành phố nhộn nhịp | にぎやかな町（まち） |
| Hoa đẹp | きれいな花（はな） |
| Đồng hồ rẻ | 安（やす）い時計（とけい） |

> Không có tính từ → chỉ biết “bát phở”; có **おいしい** → biết đặc điểm **ngon**.

---

## 5. どうですか — như thế nào?

### Cấu trúc

```
N  は  どうですか。
```

Dùng khi muốn người nghe **mô tả / đánh giá** chủ thể chưa biết rõ.

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Món ăn thế nào? | 料理（りょうり）はどうですか。 |
| → Ngon ạ. | おいしいです。 |
| Anh Nam là người thế nào? | ナムさんはどんな人（ひと）ですか。 |
| Trường học thế nào? | 学校（がっこう）はどうですか。 |
| → Yên tĩnh và đẹp. | 静か（しずか）できれいです。 |

---

## 6. とても・あまり — mức độ

| Phó từ | Đi với | Nghĩa |
|--------|--------|-------|
| **とても** | khẳng định | rất |
| **あまり** | **phủ định** | không … lắm |

```
とても  おいしいです。
あまり  おいしくありません。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Rất đẹp trai. | とてもハンサムです。 |
| Rất thú vị. | とてもおもしろいです。 |
| Không ngon lắm. | あまりおいしくありません。 |
| Không lạnh lắm. | あまり寒（さむ）くありません。 |

:::tip
**あまり** gần như luôn đi với **phủ định**.  
Sai: あまりおいしいです。
:::

---

## 7. そして・が — nối câu

| Từ | Nghĩa | Ví dụ |
|----|-------|-------|
| **そして** | và / rồi | この町（まち）は静か（しずか）です。そしてきれいです。 |
| **が** | nhưng | おいしいですが、高（たか）いです。 |

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Phòng này rộng và sạch. | この部屋（へや）は広（ひろ）いです。そしてきれいです。 |
| Ngon nhưng đắt. | おいしいですが、高（たか）いです。 |
| Thích cá nhưng không thích thịt. | 魚（さかな）が好き（すき）ですが、肉（にく）が好き（すき）じゃありません。（好き（すき） — bài sau） |

---

## 8. Tổng kết nhanh

| Loại | Trước です | Phủ định | Trước N |
|------|-----------|----------|---------|
| い | おいしいです | おいしくありません | おいしい N |
| な | 静か（しずか）です | 静か（しずか）じゃありません | 静か（しずか）な N |

**Mức độ:** とても + KĐ · あまり + PĐ  
**Hỏi cảm nhận:** どうですか  
**Nối:** そして (và) · が (nhưng)

---

## 9. Hội thoại mẫu

A: このレストランはどうですか。  
B: とてもおいしいです。そして親切（しんせつ）です。  
A: 高（たか）いですか。  
B: いいえ、あまり高（たか）くありません。  
A: じゃあ、行（い）きましょう。

---

## 10. Bài tập tự kiểm tra

1. Thời tiết hôm nay nóng.  
2. Căn phòng này không yên tĩnh.  
3. Một người nổi tiếng.  
4. Phim thế nào? → Rất hay.  
5. Không thú vị lắm.  
6. Rẻ nhưng cũ.

### Gợi ý đáp án

1. きょうの天気（てんき）は暑（あつ）いです。  
2. この部屋（へや）は静か（しずか）じゃありません。  
3. 有名（ゆうめい）な人（ひと）。  
4. 映画（えいが）はどうですか。→ とてもおもしろいです。  
5. あまりおもしろくありません。  
6. 安（やす）いですが、古（ふる）いです。
