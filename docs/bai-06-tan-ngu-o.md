# Bài 6 — Tân ngữ を · 〜を V ます／何（なに）を

> Nguồn: [Học tiếng Nhật N5 cùng Minato — Bài 6](https://www.youtube.com/watch?v=EcMPO0vFGU8&list=PLbBhikLbVlB0GaIO_rfgGtkTqSS70lS_k)

---

## 0. Lời khuyên trước khi học

Thuộc động từ hành động thường ngày: **食（た）べます、飲（の）みます、見（み）ます、読（よ）みます、します…**. Bài này giúp nói được câu có **tân ngữ** (làm gì với cái gì).

---

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

- Nói **N を Vます** (ăn cam, uống nước…)
- Phân biệt **何（なに）を** và **何（なに）をしますか**
- Dùng **N をします** (chơi bóng, tổ chức tiệc…)
- Mời / rủ: **Vませんか** · **Vましょう**
- Nói chỗ làm hành động **で**, cùng ai **と**

| # | Nội dung | Ví dụ |
|---|----------|-------|
| 1 | N を Vます | Tôi ăn cam. |
| 2 | N をします | Chơi bóng đá |
| 3 | 何（なに）を／何（なに）をしますか | Làm gì? / Ăn gì? |
| 4 | Vませんか／Vましょう | Ăn cơm không? / Ăn thôi |
| 5 | 場所（ばしょ）で・人（ひと）と | Xem phim ở rạp với bạn |

---

## 2. Tân ngữ — N を Vます

### Cấu trúc

```
N  を  V  ます。
```

**Nghĩa:** (ai đó) V đối với N.

| Ký hiệu | Vai trò |
|---------|---------|
| **N** | Tân ngữ (đối tượng hành động) |
| **を** | Trợ từ tân ngữ (đọc **o**) |
| **Vます** | Động từ lịch sự |

:::info
**を** viết を, đọc **o** (không đọc “wo” kéo dài).
:::

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi ăn cam. | わたしはりんごを食（た）べます。 |
| Uống nước hoa quả. | ジュースを飲（の）みます。 |
| Đọc sách. | 本（ほん）を読（よ）みます。 |
| Viết thư. | 手紙（てがみ）を書（か）きます。 |
| Xem phim. | 映画（えいが）を見（み）ます。 |
| Nghe nhạc. | 音楽（おんがく）を聞（き）きます。 |
| Mua bánh mì. | パンを買（か）います。 |

### Phủ định

```
N  を  V  ません。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi không ăn thịt. | わたしは肉（にく）を食（た）べません。 |
| Không uống rượu. | お酒（おさけ）を飲（の）みません。 |

---

## 3. N をします — làm / chơi / tổ chức…

Một số danh từ hoạt động đi với **します**:

```
N  を  します。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Chơi bóng đá | サッカーをします |
| Chơi tennis | テニスをします |
| Tổ chức tiệc | パーティーをします |
| Ngắm hoa | 花見（はなみ）をします |
| Mua sắm | 買い物（かいもの）をします |

---

## 4. 何（なに）を・何（なに）をしますか — hỏi đối tượng / hành động

| Câu hỏi | Dùng khi | Ví dụ trả lời |
|---------|----------|---------------|
| **何（なに）を Vますか** | Hỏi tân ngữ của động từ đã rõ | 何（なに）を食（た）べますか。→ パンを食（た）べます。 |
| **何（なに）をしますか** | Hỏi làm **việc gì** | 何（なに）をしますか。→ テニスをします。 |

### Phân biệt 何（なに）／何（なん）

- Trước **を**: thường **なに** → 何（なに）を  
- Trước âm **d/t** hoặc một số từ: **なん** (何（なん）ですか、何時（なんじ）…)

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Bạn ăn gì? | 何（なに）を食（た）べますか。 |
| Bạn làm gì? | 何（なに）をしますか。 |
| Bạn uống gì? | 何（なに）を飲（の）みますか。 |

---

## 5. 何（なに）も〜ません — không … gì cả

```
何（なに）も  V  ません。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi không ăn gì cả. | 何（なに）も食（た）べません。 |
| Không uống gì cả. | 何（なに）も飲（の）みません。 |
| Không làm gì cả. | 何（なに）もしません。 |

---

## 6. Mời / rủ — Vませんか · Vましょう

### Cấu trúc

```
V  ませんか。     ← mời / rủ (bạn có … không?)
V  ましょう。     ← đề nghị cùng làm (… thôi / chúng ta hãy…)
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Ăn cơm không? | ごはんを食（た）べませんか。 |
| Xem phim không? | 映画（えいが）を見（み）ませんか。 |
| Cùng ăn thôi. | 食（た）べましょう。 |
| Cùng đi thôi. | 行（い）きましょう。 |

### Hội thoại

A: いっしょに映画（えいが）を見（み）ませんか。  
B: いいですね。見（み）ましょう。

---

## 7. Nơi hành động で · cùng người と

### Cấu trúc câu dài

```
（人（ひと）と）  場所（ばしょ）で  Nを  Vます。
```

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi xem phim với người yêu ở rạp quốc gia. | わたしは恋人（こいびと）と国立（こくりつ）の映画館（えいがかん）で映画（えいが）を見（み）ます。 |
| Ăn cơm ở nhà ăn với bạn. | 友（とも）だちと食堂（しょくどう）でごはんを食（た）べます。 |
| Bạn ăn cơm ở đâu? | どこでごはんを食（た）べますか。 |
| Bạn xem phim ở đâu? | どこで映画（えいが）を見（み）ますか。 |

:::tip
**で** ở đây = **nơi diễn ra hành động** (khác で phương tiện ở bài 5).
:::

---

## 8. Tổng kết nhanh

| Mục | Công thức |
|-----|-----------|
| Tân ngữ | N を Vます |
| Làm hoạt động | N をします |
| Hỏi | 何（なに）を Vますか／何（なに）をしますか |
| Không gì cả | 何（なに）も Vません |
| Mời | Vませんか |
| Cùng làm | Vましょう |
| Nơi / người | 場所（ばしょ）で／人（ひと）と |

---

## 9. Hội thoại mẫu

A: きょう何（なに）をしますか。  
B: 友（とも）だちと買い物（かいもの）をします。それから映画（えいが）を見（み）ます。  
A: どこで見（み）ますか。  
B: 新宿（しんじゅく）で見（み）ます。いっしょに行（い）きませんか。  
A: いいですね。行（い）きましょう。

---

## 10. Bài tập tự kiểm tra

1. Tôi uống cà phê.  
2. Bạn đọc gì?  
3. Tôi không ăn gì cả.  
4. Chơi tennis không?  
5. → Chơi thôi.  
6. Tôi ăn cơm với mẹ ở nhà.

### Gợi ý đáp án

1. わたしはコーヒーを飲（の）みます。  
2. 何（なに）を読（よ）みますか。  
3. 何（なに）も食（た）べません。  
4. テニスをしませんか。  
5. しましょう。／テニスをしましょう。  
6. わたしは母（はは）とうちでごはんを食（た）べます。
