# Bài 14 — Thể て · nhờ vả · đang làm · 〜てください／〜ています

> Nguồn: [Học tiếng Nhật N5 cùng Minato — Bài 14](https://www.youtube.com/watch?v=Aagd7lfJCVg&list=PLbBhikLbVlB0GaIO_rfgGtkTqSS70lS_k)

---

## 0. Lời khuyên trước khi học

**Thể て** là nền tảng nhiều ngữ pháp phía sau (xin phép, cấm, nối câu…). Học thuộc cách chia 3 nhóm động từ trước khi học ứng dụng.

> Thuộc bảng chia て → rồi mới học てください／ています.

---

## 1. Mục tiêu bài học

Sau bài này bạn có thể:

- Chia động từ sang **thể て** (nhóm 1 · 2 · 3)
- Nhờ / yêu cầu lịch sự: **〜てください**
- Nói hành động **đang diễn ra**: **〜ています**
- Hỏi người khác đang làm gì

| # | Nội dung | Ví dụ tiếng Việt |
|---|----------|------------------|
| 1 | Chia thể て | 食（た）べる → 食（た）べて |
| 2 | Xin hãy… | Hãy mở cửa sổ. |
| 3 | Đang… | Đang ăn cơm. |

---

## 2. Cách tạo thể て

### 2.1. Nhóm 2 (ichidan) — dễ nhất

Bỏ **ます** → thêm **て**.

| ます | て |
|------|-----|
| 食（た）べます | 食（た）べて |
| 見（み）ます | 見（み）て |
| 起（お）きます | 起（お）きて |
| 開（あ）けます | 開（あ）けて |
| 閉（し）めます | 閉（し）めて |

### 2.2. Nhóm 3 (bất quy tắc)

| ます | て |
|------|-----|
| します | **して** |
| 来（き）ます | **来（き）て** |

### 2.3. Nhóm 1 (godan) — theo âm cuối thân ます

Lấy thân trước ます, đổi theo bảng:

| Âm cuối thân | → thể て | Ví dụ |
|--------------|----------|-------|
| い・ち・り | **って** | 会（あ）います→会（あ）って／立（た）ちます→立（た）って／売（う）ります→売（う）って |
| み・び・に | **んで** | 飲（の）みます→飲（の）んで／遊（あそ）びます→遊（あそ）んで／死（し）にます→死（し）んで |
| き | **いて** | 書（か）きます→書（か）いて |
| ぎ | **いで** | 泳（およ）ぎます→泳（およ）いで |
| し | **して** | 話（はな）します→話（はな）して |

**Ngoại lệ quan trọng**

| ます | て |
|------|-----|
| 行（い）きます | **行（い）って** (không phải いいて) |
| 来（き）ます | 来（き）て |
| します | して |

### Bảng luyện nhanh nhóm 1

| Tiếng Việt | ます | て |
|------------|------|-----|
| viết | 書（か）きます | 書（か）いて |
| nghe | 聞（き）きます | 聞（き）いて |
| chờ | 待（ま）ちます | 待（ま）って |
| lấy / cầm | 持（も）ちます | 持（も）って |
| đọc | 読（よ）みます | 読（よ）んで |
| nghỉ | 休（やす）みます | 休（やす）んで |
| nói | 話（はな）します | 話（はな）して |
| đi | 行（い）きます | 行（い）って |
| về | 帰（かえ）ります | 帰（かえ）って |
| mua | 買（か）います | 買（か）って |

## 3. Nhờ vả / yêu cầu — 「Vて ください」

### Cấu trúc

```
Vて  ください。
```

**Nghĩa:** Xin hãy làm V. / Làm V giúp với.

Lịch sự hơn khi nhờ người trên / người lạ: thêm **すみませんが** phía trước.

```
すみませんが、Vて ください。
```

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Hãy mở cửa sổ. | 窓（まど）を開（あ）けてください。 |
| Hãy đóng cửa. | ドアを閉（し）めてください。 |
| Hãy ngồi đây. | ここに座（すわ）ってください。 |
| Hãy đợi một chút. | ちょっと待（ま）ってください。 |
| Hãy viết tên của bạn. | 名前（なまえ）を書（か）いてください。 |
| Hãy nhìn bảng. | 黒板（こくばん）を見（み）てください。 |
| Hãy đọc to lên. | 大（おお）きい声（こえ）で読（よ）んでください。 |
| Xin lỗi, hãy nói chậm hơn. | すみませんが、ゆっくり話（はな）してください。 |
| Hãy chụp ảnh giúp tôi. | 写真（しゃしん）を撮（と）ってください。 |
| Mẹ ơi, để con rửa giúp nhé. → Xin lỗi, làm giúp mẹ nhé. | 母（はは）：洗（あら）ってください。 |

### Phủ định nhờ (“đừng…”) → học ở bài 17: **〜ないでください**

## 4. Đang diễn ra — 「Vて います」

### Cấu trúc

```
Vて  います。
```

**Nghĩa:** Đang làm V (hành động tiếp diễn lúc nói).

| Thể | Dạng |
|-----|------|
| Khẳng định | 〜ています |
| Phủ định | 〜ていません |
| Nghi vấn | 〜ていますか |
| Quá khứ | 〜ていました |

### Ví dụ

| Tiếng Việt | Tiếng Nhật |
|------------|------------|
| Tôi đang ăn cơm. | ごはんを食（た）べています。 |
| Mira đang làm gì? | ミラーさんは何（なに）をしていますか。 |
| → Đang làm việc. | 仕事（しごと）をしています。 |
| Đang xem TV. | テレビを見（み）ています。 |
| Đang nói chuyện điện thoại. | 電話（でんわ）で話（はな）しています。 |
| Đang viết thư. | 手紙（てがみ）を書（か）いています。 |
| Không đang ngủ. | 寝（ね）ていません。 |
| Hôm qua lúc 9 giờ đang học. | きのうの９時（じ）ごろ勉強（べんきょう）していました。 |

### Hỏi “đang làm gì?”

```
今（いま）  何（なに）をしていますか。
```

## 5. Tổng kết nhanh

| Mục | Công thức |
|-----|------------|
| Thể て nhóm 2 | bỏ ます + **て** |
| Thể て nhóm 3 | して／来（き）て |
| Thể て nhóm 1 | theo bảng って・んで・いて・いで・して |
| Nhờ vả | **Vてください** |
| Đang làm | **Vています** |

**Luôn nhớ**

1. **行（い）きます → 行（い）って** (ngoại lệ)
2. てください = nhờ lịch sự, không phải mệnh lệnh thô
3. ています = đang diễn ra (còn nghĩa trạng thái ở bài 15)

---

## 6. Hội thoại mẫu (tổng hợp)

A: すみませんが、ちょっと待（ま）ってください。  
B: はい。  
A: 今（いま）、何（なに）をしていますか。  
B: レポートを書（か）いています。  
A: じゃあ、静か（しずか）にしてください。  
B: わかりました。

---

## 7. Bài tập tự kiểm tra

Chia sang thể て, rồi dịch:

1. 飲（の）みます → ? / Hãy uống thuốc.  
2. 立（た）ちます → ? / Hãy đứng lên.  
3. 泳（およ）ぎます → ?  
4. Bạn đang nghe nhạc à?  
5. Tôi đang đọc sách.  
6. Xin hãy dạy tiếng Nhật cho tôi.

### Gợi ý đáp án

1. 飲（の）んで → 薬（くすり）を飲（の）んでください。  
2. 立（た）って → 立（た）ってください。  
3. 泳（およ）いで  
4. 音楽（おんがく）を聞（き）いていますか。  
5. 本（ほん）を読（よ）んでいます。  
6. 日本語（にほんご）を教（おし）えてください。
